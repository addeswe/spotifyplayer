Add two .NET services and Docker setup to fetch and display Spotify 'now playing' info. spotifyToken implements an OAuth flow (opens browser, listens for callback), refreshes/stores the access token in Redis (Polly retry policy) and saves it with TTL. spotifyPlayer is a minimal web app exposing /spotify/api/now-playing and /api/now-playing endpoints that read the token from Redis and proxy Spotify's currently-playing API, plus a static UI (wwwroot/index.html) to show track info and QR code. Dockerfile, docker-compose.yml and start.sh are included to build the container, install runtime deps (redis, supervisor, curl), clone the repo, start redis/nginx and run both services; docker-compose exposes port 8080 and expects SPOTIFY_CLIENT_ID/SECRET env vars. Also add .gitignore for build artifacts.
